# Automatizacion QA - Saucedemo

Proyecto de automatizacion de pruebas realizado con python para el curso de Talento Tech 2026.

## Tecnologias usadas
1. Python como lenguaje principal
2. Pytest para estructura de testing
3. Selenium WebDriver para automatizacion
4. Git para control de versiones
5. Github para control de versiones

## Instalacion
Instalar las dependencias:

...python
pip install selenium
...

...python
pip install pytest
...

...python
pip install pytest-html
...


## Ejecutar las pruebas
...python
pytest
...


## Casos de Prueba

- Validar Login exitoso
- Validar Catálogo con primer producto
- Validar añadir producto al carrito de compras
- Verificar producto al carrito de compras
